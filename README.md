# WorkingFloorAL for MikuMikuDayo

[MikuMikuDayo](https://github.com/pennennennennennenem/MikuMikuDayo)用の反射床エフェクトです。  
`WorkingFloorAL.pmx` のモーフから床の大きさ、反射合成係数、エフェクトの有効・無効を操作できます。さらに「センター」ボーンのY座標から反射面の高さを調整できます。

> 本プロジェクトはMikuMikuDayoの公式配布物ではありません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `WorkingFloorAL.fxdayo` | HLSLで記述されたYRZFXポストプロセスエフェクト |
| `WorkingFloorAL.pmx` | エフェクト操作用のPMXコントローラー |

## 対応環境

- YRZFXポストプロセスに対応したMikuMikuDayo環境で使用します。
- MikuMikuDayo本体と、`resources_pp.hlsli`・`yrz.hlsli` などのホスト側リソースは同梱していません。
- 特定のOS、GPU、MikuMikuDayoのバージョンを保証していないため、利用環境で動作確認してください。

## 変更履歴

- PMXコントローラーに「全ての親」と「センター」ボーンを追加しました。
- 「センター」ボーンのY座標を反射面の高さとして使用するようにしました。
- 「センター」ボーンの初期Y座標は `0.05` です。
- `FloorSizeX` と `FloorSizeZ` の初期値を `0.0`、最大値を `10.0` に変更しました。
- 床サイズの基準値を100 MMD座標単位へ変更し、モーフ値 `1.0` が100 MMD座標単位に対応するようにしました。

## 導入方法

1. `WorkingFloorAL.fxdayo` と `WorkingFloorAL.pmx` を同じフォルダーに置きます。
2. MikuMikuDayoで `WorkingFloorAL.pmx` を読み込みます。
3. 同名の `WorkingFloorAL.fxdayo` がポストプロセスエフェクトとして開始されます。

## コントローラー

PMXには次の4つのモーフがあります。通常はシェーダーのソースを編集せず、これらのモーフで調整してください。コントローラーモデル本体は、画面を邪魔しない不可視の構成です。

| PMXモーフ | エフェクト側の値 | 範囲 | 初期値 | 内容 |
| --- | --- | ---: | ---: | --- |
| `FloorSizeX` | `C_SizeX` | 0.0～10.0 | 0.0 | 床の横幅。1.0あたり100 MMD座標単位 |
| `FloorSizeZ` | `C_SizeZ` | 0.0～10.0 | 0.0 | 床の奥行き。1.0あたり100 MMD座標単位 |
| `Reflectivity` | `C_Reflectivity` | 0.0～1.0 | 1.0 | 反射合成係数。0.0で反射成分を使わず、値が大きいほど強く合成 |
| `off` | `C_off` | 0.0～1.0 | 0.0 | 0.0で有効、1.0で無効 |

`FloorSizeX` と `FloorSizeZ` の設定可能範囲は、それぞれ0～1000 MMD座標単位です。床はワールド座標の原点を中心とする水平面に配置され、その高さは「センター」ボーンのY座標で決まります。

PMXコントローラーには「全ての親」と「センター」ボーンがあります。「センター」ボーンの初期位置は `(0, 0.05, 0)` です。

### 反射面の高さ

「センター」ボーンのY座標が反射面のワールドY座標になります。X座標、Z座標、回転は反射面の計算には使用しません。

- `Y=0.000`: ワールド原点の高さ
- `Y=0.050`: 現在の初期値
- `Y=0.100`: ステージを `Y=-0.100` 下げた状態を基準にした比較の初期候補

スクリーンショットのように、ステージのセンターボーンを下げずに同じ相対関係を試す場合は、まず `Y=0.100` を設定してください。最終的な値は床材の位置、キャラクターの足元、カメラ角度に合わせて調整します。

このボーンは反射面だけを動かすコントローラーです。ステージ本体のセンターボーンとは別のモデルにあるため、ステージを移動しても自動追従はしません。

`Reflectivity` は反射成分の合成係数として直線的に適用されます。実際の見た目は、反射候補の有無、床の範囲、深度情報、床の細部復元などの影響を受けます。

## 動作の概要

エフェクトは次の順序で反射床を描画します。

1. カメラから各ピクセルへ伸びる視線と、「センター」ボーンで指定したワールドYの床面との交点を求めます。
2. PMXモーフで指定された床範囲と、シーンの深度情報から床として描画する領域を決めます。
3. 次の方法から反射候補を取得します。
   - 専用パスで床面の下へ反転描画した鏡像
   - 深度情報を使ったスクリーンスペース反射（SSR）
   - 複数の高さを投影して取得する部屋・背景の反射
   - 画面を床の基準線で上下反転した補助反射
4. 信頼度の高い反射を優先し、不足部分をほかの方式で補います。
5. 床の元画像に含まれる細かな陰影を少し残しながら、`Reflectivity` に従って最終画面へ合成します。

専用の鏡像描画は、黒い服や暗い物体など、明るさだけでは検出しにくい対象にも使用されます。SSRを取得できない場所では部屋投影や画面折り返しを使用し、白く無彩色に近い補助反射は白飛びを抑えるため弱められます。

スクリーンスペースを利用する方式には、画面外の物体や遮蔽された物体を完全には反射できないという制約があります。

## 制限事項

- 画面外または別の物体に遮蔽された対象は、完全には反射できません。
- 透過材質、深度情報、カメラ角度によっては反射位置や反射量が不自然になる場合があります。
- 床面は水平面に限定されます。高さは `WorkingFloorAL.pmx` の「センター」ボーンで変更できますが、傾斜や曲面には対応していません。
- 物理ベースの鏡面反射ではなく、複数の画面空間・鏡像画像を組み合わせた近似処理です。

## 見た目をソースで調整する場合

通常はPMXモーフだけで使用できます。さらに見た目を変更する場合は、`WorkingFloorAL.fxdayo` の「見た目の調整値」にある `[調整可]` の定数だけを、変更前の値を控えたうえで1項目ずつ調整してください。

主な調整値は次のとおりです。

| 定数 | 初期値 | 内容 |
| --- | ---: | --- |
| `BaseFloorUnitMMD` | 100.0 | 床サイズのモーフ値1.0に相当するMMD座標単位 |
| `FloorFeatherMMD` | 0.75 | 床端をぼかす幅 |
| `SourceFloorReflectionScale` | 0.22 | 画面内反射の強さ |
| `FallbackReflectionScale` | 1.00 | 代替反射の強さ |
| `FoldedReflectionWeight` | 0.38 | 画面折り返し反射の混合率 |
| `ReflectionGain` | 1.08 | 反射全体の明るさ |
| `ReflectionAvailabilityGain` | 8.0 | 反射候補の検出感度 |
| `ReflectionFloorBrightness` | 1.00 | 反射を重ねる前の床の明るさ |
| `ReflectionFloorLift` | 0.000 | 床色へ加える明るさ |
| `ReflectionColorBalance` | (0.92, 0.98, 1.14) | 反射のRGB色バランス |
| `ReflectionContrast` | 1.07 | 反射のコントラスト |
| `CompositeFloorDetailStrength` | 0.62 | 最終合成で残す床の細部 |
| `CompositeFloorDetailClamp` | 0.075 | 復元する床の細部の上限 |

`GridThickness = 0.018` と `GridOpacity = 0.0` は予約値です。現在の描画処理からは参照されないため、変更しても表示は変わりません。

反射の探索回数、深度許容値、鏡像の判定値などは相互に依存する上級者向けの設定です。見た目の好みだけで個別に変更することは推奨しません。

## 変更しない箇所

次の名前・構造・処理はMikuMikuDayoと各描画工程を接続するために使用されます。

- ファイル先頭の `[YRZFX]`
- `controllers`、`textures`、`passes` の名前と対応関係
- `#include`
- シェーダー関数名
- `SV_` から始まる入出力セマンティクス
- 行列、深度、UVの計算
- `#ifdef YRZ_PASS_...` の条件
- PMXのモーフ名

名前や順序を変更すると、画面が映らない、反射が消える、またはエフェクトを読み込めなくなる可能性があります。反射面の高さを変更する場合は、ソースの固定値を直接変更せず、「センター」ボーンを操作してください。

## 修正後の確認項目

見た目を修正した場合は、少なくとも次の条件で回帰確認してください。

- 暗い物体
- 白い背景
- 床の端
- カメラの近距離と遠距離
- 透過材質
- `off` モーフ
- 「センター」ボーンのY座標を `0.000`、`0.050`、`0.100`、`0.125` に変更した場合の反射位置
- ステージ床とキャラクターの足元が同じ高さの場合、および異なる高さの場合
