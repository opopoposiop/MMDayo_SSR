# WorkingFloorAL for MikuMikuDayo

[MikuMikuDayo](https://github.com/pennennennennennenem/MikuMikuDayo)用の反射床エフェクトです。  
`WorkingFloorAL.pmx` のモーフから床の大きさ、反射率、エフェクトの有効・無効を操作できます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `WorkingFloorAL.fxdayo` | HLSL Shader Model 6.xで記述されたYRZFXポストプロセスエフェクト |
| `WorkingFloorAL.pmx` | エフェクト操作用のPMXコントローラー |

## 導入方法

1. `WorkingFloorAL.fxdayo` と `WorkingFloorAL.pmx` を同じフォルダーに置きます。
2. MikuMikuDayoで `WorkingFloorAL.pmx` を読み込みます。
3. 同名の `WorkingFloorAL.fxdayo` がポストプロセスエフェクトとして開始されます。

## コントローラー

PMXには次の4つのモーフがあります。通常はシェーダーのソースを編集せず、これらのモーフで調整してください。コントローラーモデル本体は、画面を邪魔しない不可視の構成です。

| PMXモーフ | エフェクト側の値 | 範囲 | 初期値 | 内容 |
| --- | --- | ---: | ---: | --- |
| `FloorSizeX` | `C_SizeX` | 0.1～10.0 | 1.0 | 床の横幅。1.0あたり10 MMD座標単位 |
| `FloorSizeZ` | `C_SizeZ` | 0.1～10.0 | 1.0 | 床の奥行き。1.0あたり10 MMD座標単位 |
| `Reflectivity` | `C_Reflectivity` | 0.0～1.0 | 1.0 | 反射率。0.0で反射なし、0.8で80%、1.0で100% |
| `off` | `C_off` | 0.0～1.0 | 0.0 | 0.0で有効、1.0で無効 |

`FloorSizeX` と `FloorSizeZ` の設定可能範囲は、それぞれ1～100 MMD座標単位です。床はワールド座標の原点を中心とする `Y=0` 平面に配置されます。

`Reflectivity` は計算済みの反射に対して直線的に適用されます。たとえば0.5なら、反射の合成率は50%です。

## 動作の概要

エフェクトは次の順序で反射床を描画します。

1. カメラから各ピクセルへ伸びる視線と、ワールド座標 `Y=0` の床面との交点を求めます。
2. PMXモーフで指定された床範囲と、シーンの深度情報から床として描画する領域を決めます。
3. 次の方法から反射候補を取得します。
   - 専用パスで床面の下へ反転描画した鏡像
   - 深度情報を使ったスクリーンスペース反射（SSR）
   - 複数の高さを投影して取得する部屋・背景の反射
   - 画面を床の基準線で上下反転した補助反射
4. 信頼度の高い反射を優先し、不足部分をほかの方式で補います。
5. 床の元画像に含まれる細かな陰影を少し残しながら、`Reflectivity` に従って最終画面へ合成します。

専用の鏡像描画は、黒い服や暗い物体など、明るさだけでは検出しにくい対象にも使用されます。SSRを取得できない場所では部屋投影や画面折り返しを使用し、白く無彩色に近い補助反射は白飛びを抑えるため弱められます。

スクリーンスペースを利用する方式には、画面外の物体や遮蔽された物体を完全には反射できないという制約があります。

## 見た目をソースで調整する場合

通常はPMXモーフだけで使用できます。さらに見た目を変更する場合は、`WorkingFloorAL.fxdayo` の「見た目の調整値」にある `[調整可]` の定数だけを、変更前の値を控えたうえで1項目ずつ調整してください。

主な調整値は次のとおりです。

| 定数 | 初期値 | 内容 |
| --- | ---: | --- |
| `BaseFloorUnitMMD` | 10.0 | 床サイズのモーフ値1.0に相当するMMD座標単位 |
| `FloorFeatherMMD` | 0.75 | 床端をぼかす幅 |
| `SourceFloorReflectionScale` | 0.22 | 画面内反射の強さ |
| `FallbackReflectionScale` | 1.00 | 代替反射の強さ |
| `FoldedReflectionWeight` | 0.38 | 画面折り返し反射の混合率 |
| `ReflectionGain` | 1.08 | 反射全体の明るさ |
| `ReflectionAvailabilityGain` | 8.0 | 反射候補の検出感度 |
| `ReflectionFloorBrightness` | 1.00 | 反射を重ねる前の床の明るさ |
| `ReflectionFloorLift` | 0.000 | 床色へ加える明るさ |
| `ReflectionColorBalance` | (0.92, 0.98, 1.14) | 反射のRGB色バランス |
| `ReflectionContrast` | 1.07 | 反射のコントラスト |
| `CompositeFloorDetailStrength` | 0.62 | 最終合成で残す床の細部 |
| `CompositeFloorDetailClamp` | 0.075 | 復元する床の細部の上限 |

`GridThickness = 0.018` と `GridOpacity = 0.0` は予約値です。現在の描画処理からは参照されないため、変更しても表示は変わりません。

反射の探索回数、深度許容値、鏡像の判定値などは相互に依存する上級者向けの設定です。見た目の好みだけで個別に変更することは推奨しません。

## 変更しない箇所

次の名前・構造・処理はMikuMikuDayoと各描画工程を接続するために使用されます。

- ファイル先頭の `[YRZFX]`
- `controllers`、`textures`、`passes` の名前と対応関係
- `#include`
- シェーダー関数名
- `SV_` から始まる入出力セマンティクス
- 行列、深度、UVの計算
- `#ifdef YRZ_PASS_...` の条件
- PMXのモーフ名

名前や順序を変更すると、画面が映らない、反射が消える、またはエフェクトを読み込めなくなる可能性があります。現在の床面はワールド座標 `Y=0` を前提としているため、`FloorY` だけを変更しないでください。

## 修正後の確認項目

見た目を修正した場合は、少なくとも次の条件で回帰確認してください。

- 暗い物体
- 白い背景
- 床の端
- カメラの近距離と遠距離
- 透過材質
- `off` モーフ
